# Polaroids From the Past
## The Everyday Moments of a 19th Century Travel Journal

This is my portfolio project repo for the AI for the Arts and Humanities (B) course at the University of Glasgow.

### About

This project uses AI image generation to create a collection of 15 Polaroid images depicting everyday moments from MS Gen 13, which is a travel journal written by Andrew MacGeorge.

### Repository Structure

```
images/                         # Containing all images for the Jupyter notebook
AI-B_Portfolio_2266360L.ipynb   # The project Jupyter notebook
README.md                       # This file
```

### Tools Used

- ChatGPT: image generation and caption drafting
- Jupyter Notebook: project presentation

### Primary Source

MS Gen 13, University of Glasgow Archives and Special Collections.
Digitally transcribed by Robert MacLean.
